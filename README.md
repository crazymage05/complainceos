## One-Line Pitch

> An AI agent that builds a unique Compliance DNA for your small business, tracks every regulatory deadline with a decay score, detects when new laws ripple through your obligations, predicts penalties before they happen, and auto-drafts filing-ready documents — all for ₹500/month instead of ₹5 lakh/year.

---

## The Problem

India has **64.5 million MSMEs** facing over **1,450 compliance obligations per year** across GST, income tax, labour law, FSSAI, Shop & Establishment, and dozens of state-level regulations. Average annual compliance cost: **₹13–17 lakh**, mostly spent on CA retainers to track deadlines. Regulators issue **42 regulatory updates every single day**. Result: ₹89,000 crore in penalties collected from MSMEs annually — almost entirely from missed deadlines, not wilful evasion.

## 5 Core Features (Patent Pending)

### 1. Compliance DNA Profile
Every business gets a unique obligation fingerprint computed from industry, turnover, employee count, state, registrations, and **business age**. A 1-month-old business gets only essentials (8–12 obligations). A 2-year-old established business gets the full profile (40–50 obligations). New businesses are never overwhelmed on day one.

### 2. Regulatory Decay Score
Composite urgency metric combining days-to-deadline, filing complexity, penalty magnitude, and historical on-time rate into a single 0–100 score. Obligations decay toward zero as the deadline approaches. Formula:

```
score = clamp(
  (days_remaining / total_days) × (1/complexity) × (1/penalty_severity) × on_time_rate × 100,
  0, 100
)
```

### 3. Regulatory Ripple Detection
When a regulation changes, a dependency graph traces every downstream obligation affected. One GST circular can ripple into 12 filing changes — ComplianceOS catches all of them automatically.

### 4. Penalty Prediction Engine
Entity-specific financial forecasting: exact penalty the business faces if a deadline is missed, given their turnover band, prior defaults, and the penalty formula in the Act. Not a generic warning — a specific rupee figure.

### 5. Auto-Draft Filing Agent
Pre-populated filing documents generated by the Gemini agent using the business's stored profile. Pulls the relevant template, fills known fields, exports PDF-ready for government portal upload.

## User Flow

```
Sign in (Google)
    ↓
Onboarding — fill business profile + incorporation date
    ↓
AI generates obligation set (DNA Builder)
    ↓
Review Screen — user customises:
  • Uncheck obligations that don't apply
  • Set their own due dates per obligation
  • Remove anything irrelevant
    ↓
Dashboard — personalised compliance calendar:
  • Overview tab — urgent + warning obligations + ripple alerts
  • Obligations tab — full list with filter (urgent/warning/on-track)
  • Ripple Alerts tab — regulatory change notifications
  • Documents tab — auto-generated draft queue + approve/file
  • History tab — filing record with on-time rate
```

## Setup

### Prerequisites
- Python 3.11+
- Node.js 18+
- MongoDB Atlas account — [cloud.mongodb.com](https://cloud.mongodb.com)
- Gemini API key — [Google AI Studio](https://aistudio.google.com)
- Firebase project with Google Auth enabled
- Google Cloud service account key (`gcloud-key.json`)

### Backend

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env
# Fill in MONGODB_URI, GEMINI_API_KEY, GOOGLE_CLOUD_PROJECT, etc.
python db/seed_corpus.py       # Seeds 90 regulations, 26 penalty rules, 10 templates
uvicorn main:app --reload      # http://localhost:8000
# Docs at http://localhost:8000/docs
```

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
# Fill in VITE_API_URL and Firebase config
npm run dev                    # http://localhost:5173
```

### MongoDB MCP Server

`backend/mcp_config.json` configures the Atlas MCP Server for direct agent tool calls:

```json
{
  "mcpServers": {
    "mongodb": {
      "command": "npx",
      "args": ["-y", "mongodb-mcp-server"],
      "env": {
        "MDB_MCP_CONNECTION_STRING": "<your Atlas connection string>"
      }
    }
  }
}
```
