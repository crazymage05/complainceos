## One-Line Pitch

> An AI agent that builds a unique Compliance DNA for your small business, tracks every regulatory deadline with a decay score, detects when new laws ripple through your obligations, predicts penalties before they happen, and auto-drafts filing-ready documents — all for ₹500/month instead of ₹5 lakh/year.

---

## The Problem

India has **64.5 million MSMEs** — the backbone of its economy — yet each business faces over **1,450 compliance obligations per year** across GST, income tax, labour law, FSSAI, Shop & Establishment, and dozens of state-level regulations. The average annual compliance cost runs between **₹13–17 lakh**, most of it spent on CA retainers just to track deadlines. Regulators issue **42 regulatory updates every single day**, and small business owners have no system to absorb that change. The result: ₹89,000 crore in penalties collected from MSMEs annually — almost entirely from missed deadlines, not wilful evasion. ComplianceOS fixes this.

## Architecture

```
[Business Owner] → [React Dashboard] → [FastAPI Backend]
                                              ↓
                              [Gemini 2.0 Flash via Google ADK]
                                              ↓
                              [MongoDB Atlas via MCP Server]
                              (8 collections: businesses, regulatory_corpus,
                               obligation_instances, regulatory_changes,
                               penalty_rules, filing_templates,
                               filing_history, agent_decisions)
```

The agent receives natural-language or structured requests from the FastAPI backend, reasons over the MongoDB collections via the MCP Server's tool interface, and returns structured outputs (decay scores, ripple maps, penalty estimates, draft documents) that the React dashboard renders in real time.

---

## 5 Core Features

1. **Compliance DNA Profile** — Every business gets a unique obligation fingerprint computed from its industry, turnover, employee count, state, and licences. Instead of showing every MSME every rule in India, ComplianceOS shows only what legally applies to *this* business.

2. **Regulatory Decay Score** — A composite urgency metric (Patent Pending) that combines days-to-deadline, filing complexity, penalty magnitude, and historical lateness into a single 0–100 score. Obligations "decay" toward zero the closer the deadline looms — giving owners a single number to act on every morning.

3. **Regulatory Ripple Detection** — When a new notification amends a parent regulation, a dependency graph (Patent Pending) traces every downstream obligation that changes as a result. One GST circular can ripple into 12 filing changes — ComplianceOS catches all of them automatically.

4. **Penalty Prediction Engine** — Entity-specific financial forecasting (Patent Pending) that calculates the *exact* penalty an owner faces if they miss a specific deadline, given their turnover band, prior defaults, and the penalty formula in the Act — not a generic warning, but a rupee figure: "You owe ₹12,400 if you miss 15 June."

5. **Auto-Draft Filing Agent** — Pre-populated filing documents (Patent Pending) generated by the Gemini agent using the business's stored profile data. The agent pulls the relevant template, fills in all known fields, flags gaps for the owner to complete, and exports a PDF ready to upload to the government portal.

## Tech Stack

| Layer | Tool | Why |
|---|---|---|
| Agent Brain | Gemini 2.0 Flash | Google AI Studio free tier, fast reasoning, 1M context window |
| Orchestration | Google Cloud ADK 2.0 | Official Google agent framework — satisfies hackathon requirement |
| MCP | MongoDB Atlas MCP Server | Direct agent-to-database tool calls, no custom wrapper needed |
| Database | MongoDB Atlas (Free) | Flexible schema for heterogeneous regulatory corpus |
| Backend | Python + FastAPI | Async, fast, Pydantic validation, easy OpenAPI docs |
| Frontend | React 18 + Tailwind | Component-based, responsive, fast hot-reload with Vite |
| Auth | Firebase Auth | Google sign-in, free tier, zero backend session management |
| Deploy | Vercel + Railway | Zero-config CI/CD, free tier covers hackathon traffic |

## Setup

### Prerequisites

- Python 3.11+
- Node.js 18+
- MongoDB Atlas account (free tier at [cloud.mongodb.com](https://cloud.mongodb.com))
- Gemini API key from [Google AI Studio](https://aistudio.google.com)
- Firebase project with Authentication enabled

---

### Backend

```bash
cd backend
pip install -r requirements.txt
cp .env.example .env
# Fill in your credentials in .env
python db/seed_corpus.py  # Seeds 90 India compliance obligations
uvicorn main:app --reload
```

The API will be available at `http://localhost:8000`. Interactive docs at `http://localhost:8000/docs`.

---

### Frontend

```bash
cd frontend
npm install
cp .env.example .env
# Fill in VITE_API_URL and Firebase config
npm run dev
```

The dashboard will be available at `http://localhost:5173`.

---

### MongoDB MCP Server

The `mcp_config.json` at the project root configures the MongoDB Atlas MCP Server to give the Gemini agent direct read/write access to all 8 collections. Paste your Atlas connection string into the config before running the agent.

```json
// mcp_config.json — already included in this repo
{
  "mcpServers": {
    "mongodb": {
      "command": "npx",
      "args": ["@mongodb-js/mongodb-mcp-server"],
      "env": {
        "MDB_MCP_CONNECTION_STRING": "<your Atlas connection string>"
      }
    }
  }
}
```
